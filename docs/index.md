ShellQuest es un videojuego educativo desarrollado en Python y Pygame que busca enseñar los fundamentos de Linux mediante exploración, comandos de terminal y desafíos interactivos.

## Objetivos del proyecto

Aprender a navegar por el sistema de archivos de Linux.
Practicar comandos como pwd, ls y cd.
Aplicar programación orientada a objetos (POO).
Diseñar una arquitectura mantenible utilizando principios SOLID.
Estado del proyecto

En desarrollo: primer nivel de exploración del sistema de archivos.
